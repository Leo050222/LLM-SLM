# 各 bridge token 支持力度下的正确率提升档位与题目去重统计

## 统计口径

- 每个 `(prefix, source bridge)` 的正确率由 8 次 Student continuation 计算。
- 相对同一原 prefix 的 8 次直接 Student rollout，正确次数每变化 1 次对应 12.5 pp。
- 每个 horizon 有 105,952 个 bridge 组。
- “去重题目数”按 `problem_id` 去重。全数据 13,244 个 prefix 对应 13,244 个唯一 `problem_id`，所以它也等于该档位的去重 prefix 数。
- 同一道题的 8 个 source bridge 可能落入不同提升档位，因此各档位的去重题目数不能相加。

## 主要观察

1. 随着 bridge 从 32 增至 256 tokens，分布明显右移：−25、−12.5 和 0 pp 档位持续减少，+25 pp 及以上档位整体增加。
2. +12.5 pp 档位没有随 bridge 长度增加，反而略降；更长 bridge 主要把质量推向 +25 pp 以上的中高提升档位。
3. +100 pp 档位增长最明显：bridge 数从 157 增至 731，去重题目数从 37 增至 275。
4. 0 pp 档位覆盖大量题目，是因为同一道题的不同 bridge 经常都保持与原 prefix 相同的 8 次正确数；所以 bridge 数与去重题目数的差距较大。
