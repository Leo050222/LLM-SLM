## 优先分析（现有逐题数据）

1. 同题正确性转换矩阵、短长各自独有成功、按题配对 bootstrap；BBH 分子任务，控制探索性多重比较。相同随机 seed 不保证轨迹随机性匹配，补独立种子。
2. 按平均实际 teacher token 绘制准确率前沿；另画调用次数。单种子前沿只描述观测值。
3. 逐题最优 k 只作有选择偏差的探索性上界；独立随机性和留出题评估才能判断是否存在可预测的异质性。
4. 检查交还后再触发距离、触发密度、答案输出位置。按生成长度/可观察区间处理截尾；更长接管吞掉潜在触发位置，次数减少不能证明状态恢复。

## 新实验一：同状态长度效用

从固定参考策略的轨迹采样 anchor，不按结果挑选；按 gap、已生成位置、任务、此前介入次数分层。先用 100–200 个 anchor 做 pilot，每题少量 anchor，按问题划分训练/验证/测试。

动作 k∈{0,1,4,8,16}：k=0 保留原 student 草稿 token 后继续；k>0 teacher 接管后 student 完成，禁止后续 teacher 帮助。增加屏蔽原 token 后 student 自采样控制。初期保持当前 teacher 首 token ban 不变。

对每个 anchor 采样若干 teacher continuation，用同一 continuation 的嵌套前缀构造各 k，再各自采样多个 student future；先 4–8 个 future，置信区间宽的状态再追加。共享 teacher 前缀降低长度比较中的内容混杂，不将一个 teacher continuation 的偶然性当作规律。EOS 提前结束按实际长度记账。

估计 V(s,k)=P(最终正确|状态 s,动作 k,之后 student 独立完成)。定义预算权衡 argmax_k[V(s,k)-λ E(T_teacher|s,k)]，或者选距离最佳 V 不超过 ε 的最短 k；后者必须考虑估计误差。该目标只度量 teacher 生成预算。

判定重点：短足够、长有益、长有害、均无法恢复四种响应是否跨重复稳定；gap 能否区分响应？不能预设 gap 越大应给越长。

## 新实验二：固定预算的闭环比较

固定 τ=2.5 起步，在统一停止规则、统一首 token ban、相同总 teacher token 上限下比较固定 k、随机长度（匹配长度分布）、按 gap 的简单分桶长度和状态预测长度。预算 16/32/64，报告实际 token、次数、准确率。验证集选规则，测试集冻结。再在 τ=2 或另一模型对验证稳健性。

同状态的独立完成效用与允许后续干预的闭环效用不同；最终策略必须单独在线验证，不能用离线分支效用替代闭环结果。

## 新实验三：可观察的交还规则

先预测一次性 k，再研究 1→4→8→16 的逐步接管。交还特征只能来自当时可观察信息：student 对 teacher continuation 的支持、局部不确定性、已用预算、此前再触发历史等。Student 高置信可能错误，teacher/student 一致也不是正确性证明。

若用 student 草稿探测是否可交还，必须从当前 teacher prefix 重采样，旧 anchor 后草稿已失效；探测和 teacher 评分额外成本记账。稳定支持是否预测成功先做离线检验，再形成停止规则。

## 研究主张

当前支持：固定介入长度的收益呈任务与阈值相关的非单调关系，短介入在若干设置下已接近更长介入的准确率。

仍待证明：介入长度需求是否具有稳定且可预测的状态差异，以及动态策略是否在留出数据、多个种子和另一模型对上优于调优后的固定长度策略。
