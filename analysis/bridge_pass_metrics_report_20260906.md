# 不同 bridge token 支持力度的 pass 指标

## 统计口径

- 一个 bridge 组指一个 `(prefix, source bridge)`，包含 8 次独立 Student continuation。
- `pass all 8`：8 次全部正确，即 8/8。
- `pass@8`：8 次中至少一次正确，即正确次数大于 0。
- `提升`：当前 bridge 组的 8 次正确数严格大于同一原 prefix 的直接 Student 8 次正确数。
- 每个 bridge horizon 有 105,952 个组（13,244 prefixes × 8 source bridges）。直接 Student 基线有 13,244 个 prefix 组。

## 结果

| 条件 | Pass all 8 | 相对直接 Student | Pass@8 | 相对直接 Student | 正确次数提升 | 不变 | 下降 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 直接 Student | 1,560 / 13,244 = 11.7789% | — | 9,110 / 13,244 = 68.7859% | — | — | — | — |
| 32-token | 13,989 / 105,952 = 13.2031% | +1.4242 pp | 73,986 / 105,952 = 69.8297% | +1.0439 pp | 31,399 = 29.6351% | 44.0398% | 26.3251% |
| 64-token | 14,876 / 105,952 = 14.0403% | +2.2614 pp | 73,936 / 105,952 = 69.7825% | +0.9967 pp | 32,376 = 30.5572% | 43.4178% | 26.0250% |
| 128-token | 16,440 / 105,952 = 15.5165% | +3.7375 pp | 74,116 / 105,952 = 69.9524% | +1.1666 pp | 34,183 = 32.2627% | 42.6344% | 25.1029% |
| 256-token | 20,702 / 105,952 = 19.5390% | +7.7601 pp | 74,060 / 105,952 = 69.8996% | +1.1137 pp | 37,724 = 35.6048% | 41.1583% | 23.2369% |

## 结论

1. `pass all 8` 随 bridge 长度单调且明显提高，从直接 Student 的 11.78% 增至 256-token 的 19.54%。
2. `pass@8` 基本饱和在 69.8%–70.0%；各 horizon 相比直接 Student 只增加约 1.0–1.2 pp，128-token 最高但差异很小。
3. “正确次数严格提升”的占比随 token 支持力度单调增加：29.64% → 30.56% → 32.26% → 35.60%；同时下降占比从 26.33% 降至 23.24%。
4. 这说明更长 bridge 的主要作用不是大幅扩展“至少能成功一次”的 prefix 覆盖面，而是把已有成功可能性的样本推向更稳定的多次成功乃至 8/8 全对。
