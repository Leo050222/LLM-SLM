# 异步推理实现与真实试验

实现目录：experiments/grid_async_retry_20260916。原始版本保留在experiments/grid_async_20260916。

每GPU单一AsyncLLM，capacity/max_num_seqs保持8，明确使用与同步LLM一致的LLM_CLASS配置上下文。FIFO选取尚未执行的有效请求，用inflight集合去重。每请求独立获取FINAL_ONLY结果、校验评分位置并返回，空位立即补入。共享文件锁/租约语义保留，阻塞磁盘操作移至有界线程池。最后有效租约到期才取消引擎请求；后续新等待者可重新执行。模型、SamplingParams除输出交付模式外保持一致。

本地/远端4项异步单元测试通过：短请求完成立即补入而长请求仍运行、容量上限与无重复执行、最终租约到期取消/重新加入、多个等待者超时隔离、错误传播（前两项同一测试）。参数AST对照通过。

资源：代码FIFO作业104996持续运行。数学原104997停止后，105028在同一八卡预算内开始试验；其引擎成功初始化，但benchmark错误假设dataset_index从0开始，读取00000.json失败，未进入测速。该作业自动回退FIFO并通过全部服务烟测继续产出。修正版本根据prompts.jsonl真实索引选取并在登录节点预验证13个已完成非超时样本，覆盖BBH/MATH500/OlympiadBench。105028随后停止，归档后由105032在相同节点八卡预算内重试。

三轮真实对照使用同节点两对同步模型、两对异步模型。每轮相同固定请求：双方forced-token评分、学生1/8/32/64token生成、教师带首token禁止的1token生成。跨轮改变seed/前缀避免RPC结果缓存命中。报告实际token评分差异、同步双副本自身差异、五阈值决策、采样token匹配与RPC吞吐。接受条件：评分最大绝对差<=1e-4、所有阈值决策一致、三轮中位吞吐提升>=5%；否则自动恢复FIFO。此门槛只证明固定RPC回放，不等于全任务端到端加速。
