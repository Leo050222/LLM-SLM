# 连续支持度分析：偏好差 D 与累计概率位置 M

2026-09-21；全部 399,601 个介入点；仅读取既有指标，无新增 rollout。两个指标均来自同一历史前缀上的 student 重放分布。x 为原 student token，y 为实际 teacher token。

## 主要发现

teacher token 常在排名前列，但相对原 student token 的概率优势通常不接近；在概率质量的意义下，它也经常位于分布尾部。不能把“top-5”直接理解成“两个主要候选之间犹豫”。

- D 中位数为 **2.75 nats**，即 student 对 x 的概率是对 y 的约 **15.6 倍**。
- M 中位数为 **94.13%**：对中位事件而言，概率高于 y 的 token 已经占据 student 94.13% 的概率质量。这不是 y 自身的概率。
- 约 **12.36%–12.41%** 的事件同时满足“x/y 概率相差≤2倍、y 位于覆盖90%概率质量的核心集合内”。
- 约 **34.23%–34.50%** 的事件同时满足“student 对 x 的偏好≥10倍、y 位于99%核心集合之外”。

后两项范围来自 BF16 并列排序，不是置信区间。按保守归属，这两组分别为 12.36% 和 34.23%，其余 53.41% 不强行归入任一类。这两个比例只是连续分布上的可读切片，不是天然类别，也不表示路径正确性。

## 定义与并列处理

\[
D=\log p_w(x)-\log p_w(y),\qquad M_{lo}=\sum_{v:p_w(v)>p_w(y)}p_w(v)
\]

D=0 表示偏好相等；D>0 表示更偏好原 token；D<0 表示更偏好 teacher token。M 越接近1，说明越多概率分配给比 y 更优先的候选。

并列 token 的顺序不确定，定义 M_hi=M_lo+Σ_{v:p_w(v)=p_w(y)}p_w(v)−p_w(y)。y 确定处于 q 核心集合内当 M_hi<q，确定处于集合外当 M_lo≥q；其余为并列边界。核心集合按概率从高到低累计至至少 q，包含使累计质量跨越 q 的 token。

## 阈值敏感性

固定 y 在90%核心集合内，逐步放宽“候选偏好接近”的条件，保守占比为：

| x/y 概率允许相差 | 占全部介入 |
|---|---:|
| ≤1.5倍 | 7.68% |
| ≤2倍 | 12.36% |
| ≤3倍 | 20.22% |
| ≤10倍 | 36.78% |

固定相差≤2倍，把核心集合从80%放宽到90%、95%、99%概率质量，占比依次为 **11.73%、12.36%、12.63%、12.81%**。在这些范围内，接近候选的占比更依赖“接近”的倍数定义，而不是核心集合的具体 cutoff。

从尾部看：

| 核心集合覆盖质量 | y 确定在集合外 | 同时 student 对 x 偏好≥10倍 |
|---|---:|---:|
| 90% | 56.80% | 53.02% |
| 95% | 48.62% | 47.44% |
| 99% | 34.38% | 34.23% |
| 99.9% | 22.15% | 22.14% |

越深入尾部，y 几乎总是同时被 student 相对 x 强烈降权；例如99%集合外的34.38%事件中，34.23个百分点也满足≥10倍偏好差。不能把表中不同阈值的比例相加。

## 数值检查与限制

- 全量输入 hash、事件数、唯一ID、D 与既有log比一致性、累计质量范围与核心/尾部互补检查通过。
- 40个覆盖各数据集和概率/并列极值的原BF16事件，以独立NumPy FP64复算D、M通过；最大累计质量误差3.59e−7。
- 原FP32归约有7,590行的累计质量略超1，最大为1.0000003631；仅裁正概率边界舍入，未从统计中删除。这里最严格展示的核心边界为0.9999，不把1−M当高精度极小尾概率估计。
- 小校准误差（两模型原token误差均≤0.1）子集中，两组保守占比为11.14%/31.54%；大误差>1子集为3.29%/62.52%。两组相对大小方向一致，比例会随子集组成变化。
- 八轮保守占比的均值±轮间样本标准差分别为12.358%±0.090个百分点、34.235%±0.284个百分点。
- 这是历史介入点上的重放分布，不是历史vLLM实际采样张量，也不代表所有生成位置。“接近”仅指两个实际候选偏好接近；“尾部”仅指student低支持，不能据此声称teacher选对或弱模型完全走错。
