## 结论

1. **在冻结重放分布中，强模型的实际 token 通常位于弱模型已有的前列候选。** 76.92% 的介入中，该 token 确定属于弱模型 top-5；87.21% 属于 top-10。严格低支持组（排名下界>50 且概率<0.1%）占 3.91%。这支持“已有候选中的替换更常见”的描述，不能直接推出选择正确或收益主要来自该组。
2. **排名靠前与采样概率高是不同概念。** 原始弱概率中位数 3.1246%，P10 仅 0.000176%，P90 为 56.20%；26.20% 的事件中实际强 token 的弱概率低于 0.1%。只有 42.75%–43.20% 位于弱模型的 90% nucleus 内（区间为并列顺序界）。弱模型可能高度集中于原 token，即使替代 token 排名第二，其绝对概率也很低。禁止原 token 后，实际强 token 的弱概率中位数升至 32.05%。这是两个边际中位数，不能解释为典型事件的概率提升倍数。
3. **数据集差异明显。** CruxEval-I/O 的低支持组分别为 20.36%/11.88%；其他数据集为 0.50%–3.61%。不能把所有任务概括成同一种机制。
4. **总体强模型分布更集中，但该结论依赖子集。** 事件等权平均熵：弱 0.7307、强 0.6463 nats，配对差 +0.0844；58.53% 的介入点弱熵更高。校准误差≤0.1 的子集中差值为 −0.0598，方向反转，不能宣称强模型在所有可靠测量子集中都更低熵。低熵本身也不代表更正确。

## 覆盖与统计口径

- 8 数据集、8 轮、4,571 题、36,568 条轨迹；399,601 个介入事件全部覆盖，无重复或丢失。
- 4,549 题至少有一次介入；816 条轨迹无介入（2.23%），其支持度不填零。227 条生成超时轨迹保留，单独切片。
- 历史评分全部匹配 source SHA256，无缺失评分文件；6 条存在评分/提取异常状态：3 scoring_execution_timeout、2 solution_process_crash、1 extraction_missing。保留历史评分值，单独输出清单和排除敏感性，不能将其视为已确认的模型错误。
- 模型：Qwen3-1.7B / Qwen3-14B。每个事件读取相同历史前缀下的完整 151,936 维 BF16 logits，转 FP32 归一化；T=1。历史强替换屏蔽原弱 token x。
- p_w(y) 使用未屏蔽弱分布；q_w(y) 使用屏蔽 x 后重归一化的弱分布。后者是简单排除原动作的分布对照，不是已运行的反事实成功率。
- BF16 并列保留最优/最差排名；主表 top-k 用最差排名仍≤k 的保守覆盖。强 token 的最佳排名中位数为 2，最差排名中位数为 3。
- CI 为 2,000 次题目聚类 bootstrap，同题的所有轮次/事件一起重采样。区间反映固定这八轮下的题目变异，不包含模型重放偏差。
- 题目等权：先每条有介入轨迹的事件均值，再题内有介入轮次等权，再题等权。数据集宏平均额外对八数据集等权。

## 熵与稳健性

原始平均配对熵差 H_w−H_s=0.0844 nats，95% CI [0.0759,0.0952]；中位差 0.0712。禁止 x 后，两模型平均熵为 0.7663/0.5800，平均差增至 0.1863。数据集宏平均、集内题等权的原始差为 0.1584 [0.1512,0.1654]。

高支持组在全部八数据集均表现为弱熵更高；低支持组在 BBH、HumanEval+、LiveCodeBench、Math500、MBPP+、OlympiadBench 中原始平均熵差为负。特别是低支持 token 可能来自一个非常自信但拒绝该 token 的弱分布，“弱模型犹豫”不是所有介入的解释。

| 敏感性子集 | 事件数 | 高支持 % | 低支持 % | 平均原始熵差 |
|---|---:|---:|---:|---:|
| 全量 | 399601 | 57.26 | 3.91 | +0.0844 |
| 排除阈值/并列边界 | 385920 | 58.30 | 4.04 | +0.0913 |
| 两模型原 token 校准最大误差≤0.1 | 161514 | 57.12 | 2.94 | −0.0598 |
| 两模型原 token 校准最大误差>1 | 1126 | 33.93 | 11.72 | +0.2808 |
| 排除生成超时 | 392501 | 57.07 | 3.94 | +0.0805 |
| 排除 EOS/空白/纯标点的词面初筛 | 274342 | 56.02 | 3.54 | +0.0538 |

边界事件 3.42%；排除后高支持占比仅改变 +1.04 个百分点。r0 对 r1–r7，各数据集高支持比例差最大约 1.40 个百分点。完整八轮、校准分箱、首个/后续介入、正确/错误、超时、词面类型、阈值网格见 CSV。

八轮分别做全事件汇总后，轮间均值±样本标准差：高支持 57.26%±0.25 个百分点，低支持 3.91%±0.06 个百分点，原始熵差 0.08437±0.00433 nats。这是轮间波动描述，不替代题级 bootstrap。排除 6 条评分异常轨迹涉及的 158 个事件后，高支持为 57.261%、平均熵差 0.08438，主分布指标基本不变。

校准较小和较大子集的熵方向不同，严格高支持多数也在大误差子集失效。因此按原计划不下“统一主导机制”的稳健结论；当前可陈述的是完整重放总体上的候选支持结构。子集差异可能同时包含数据组成和数值误差影响，尚未分离。词面筛选也不能代替逻辑语义标注。

## 重放可靠性与计算验证

| 对历史原 token logprob 的绝对误差 | 弱模型 | 强模型 |
|---|---:|---:|
| P50 | 0.01469 | 0.10337 |
| P90 | 0.15477 | 0.25000 |
| P95 | 0.21869 | 0.40136 |
| P99 | 0.44805 | 0.70192 |
| 最大值 | 4.92521 | 4.73857 |

这些是 logprob 差，不是概率百分点。历史 teacher top-16 平均重合率 98.84%，容许 BF16 cutoff 并列后为 99.31%。重放下 2.256% 的既有触发点 gap≤2，未据此删除任何事件。15.79% 的目标 token 存在并列排名。

测量是固定历史前缀上的 Transformers SDPA BF16 重放，不是历史 vLLM 实际采样张量。历史 p_w(y) 未保存，因此不能直接验证其排名漂移；x 的误差不能作为 y 的误差保证。独立 FP64 复算仅验证本次归档指标计算的正确性，不消除后端重放偏差。

独立验证覆盖每数据集首尾、概率极值、最大并列数，共 40 个事件、560 项检查全部通过，最大绝对差 1.91e−6。全量提取和汇总检查覆盖总数、唯一键、hash、归一化、熵界、排名、评分联接。
