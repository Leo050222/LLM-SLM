# 实际 teacher token 与原 student token：配对采样概率

2026-09-21；399,601 个历史介入点。x 是被替换的原 student token，y 是实际 teacher token。

## 核心结论

**在同一个 student 分布下，两者的概率通常相差很大。** 逐事件概率比 R=p_w(y)/p_w(x) 的中位数为 0.06393，即 teacher token 的概率约为原 token 的 1/15.6。只有 12.83% 的事件满足 0.5≤R≤2；仅 6.02% 的事件两者绝对概率差≤5 个百分点。

这补充了上一阶段的结论：teacher token 往往排名靠前，但 student 对原 token 的偏好经常显著更强。排名第二、第三不意味着与第一名的概率接近。本结果尚不证明替换改善正确率。

## 概率的边际分布

两列都来自**同一前缀、同一个未屏蔽的 student 分布**，T=1，不混入 teacher 自己的 softmax。

| 统计量 | 原 student token 的 p_w(x) | teacher token 的 p_w(y) |
|---|---:|---:|
| 均值 | 61.36% | 16.05% |
| P10 | 8.909% | 0.000176% |
| P25 | 30.39% | 0.07458% |
| P50 | 68.37% | 3.125% |
| P75 | 95.24% | 22.27% |
| P90 | 99.81% | 56.20% |

不能用上述两个边际中位数相减/相除，充当配对差/配对比的中位数。以下结果均先在每个事件内计算差值、比值，再统计。

## 配对差距

简化分类补充（分母均为 399,601，2026-09-21）：两个实际候选在 student 下概率都≥10%，且概率比在 [0.5,2]，共 45,356 次（11.35%），作为“高概率、相近候选”的操作定义。teacher token 的 student 概率<0.1%：104,698 次（26.20%）；<0.01%：72,148 次（18.06%）；<0.001%：50,526 次（12.64%）。后三个阈值相互包含，不能相加。原 student token 概率≥90% 且 teacher token 概率<0.1%：66,772 次（16.71%）。以上衡量候选概率和模型偏好，不单独证明路径对错。

| 指标 | 事件等权结果 |
|---|---:|
| 平均 p_w(y)−p_w(x) | −45.31 个百分点，95% CI [−46.06,−44.60] |
| p_w(y)−p_w(x) 中位数 | −56.73 个百分点 |
| 绝对差中位数 | 64.08 个百分点 |
| R 中位数 | 0.06393 |
| 两者相差不超过 2 倍 | 12.83%，95% CI [12.61,13.06] |
| 两者相差不超过 10 倍 | 40.67% |
| teacher token 概率低于原 token 的 1/10 | 54.90%，95% CI [54.30,55.51] |
| teacher token 概率低于原 token 的 1/100 | 36.05% |
| 绝对差≤1 个百分点 | 2.80% |
| 绝对差≤5 个百分点 | 6.02%，95% CI [5.86,6.18] |
| 绝对差≤10 个百分点 | 9.84% |
| 同时满足相差≤2倍、绝对差≤5个百分点 | 3.95% |
| teacher token 概率更高 | 18.29% |
| 概率相等（重放 BF16 并列） | 1.97% |
| teacher token 概率更低 | 79.74% |

23.01% 的介入点同时满足 p_w(x)≥90% 且 p_w(y)<1%。因此，至少这一子集不能描述为 student 在两个近似等概率的候选之间犹豫。

数学任务中的概率相对接近一些，但即使在 Math500，也只有约 1/5 的事件两者处于 2 倍以内。CruxEval 的概率分歧最明显。

## 稳健性与解释范围

题目等权（题内先有介入轮次等权，再题等权）下，平均差为 −52.83 个百分点 [−53.63,−52.01]；相差≤2倍的比例为 10.61% [10.29,10.95]。结论不是由少数长轨迹独占事件量造成的。

两模型原 token 校准最大误差≤0.1 的子集有 161,514 个事件，其平均差 −50.24 个百分点，相差≤2倍占 11.56%；误差>1 子集对应 −36.77 个百分点、3.91%。方向一致，但 x 的校准不能保证 y 的重放精度。八轮“相差≤2倍”比例的样本标准差为 0.095 个百分点。

所有概率来自已归档的相同历史前缀 BF16 重放，而非历史 vLLM 原始采样张量。置信区间为 2,000 次题目聚类 bootstrap，不包括重放系统误差。原 x 是从 student 分布中实际采样得到，而且这些位置经过介入触发筛选，存在选择效应；不能把这里的分布外推到所有生成位置。

如果另问“各模型对自己抽出的 token 有多自信”，teacher 在屏蔽 x 后的 q_s(y) 中位数为 93.29%，student 的 p_w(x) 中位数为 68.37%。这比较的是**两个不同分布**，并不能回答 student 对 x 和 y 是否同样愿意选择，因此不作为上述主结论的证据。teacher 未屏蔽的 p_s(y) 中位数为 89.86%。

下一步可在已规划的三分支反事实中预先加入 R 分箱：检验“强烈违背弱模型偏好”的替换与“近概率替换”分别带来多少局部完成收益。当前只报告分布，不把分歧等同于纠正。
