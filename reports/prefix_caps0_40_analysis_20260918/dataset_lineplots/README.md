# Per-dataset line plots

Eight datasets, three panels each: mean accuracy, empirical pass@8 (any of 8 correct), pass all 8 (all 8 correct). X-axis: intervention caps 0–20, 25, 30, 35, 40, placed at their actual numeric distances. Lines connect observed budgets; missing budgets were not evaluated. Dashed line: teacher-only from the original prompt. Intervention runs share a frozen student prefix. Each dataset has 100 problems × 8 rollouts/cap. All panels use the same 0–100% y-axis; all values are percentages.

Source: ../metrics.json. Combined PDF: all_datasets_three_metrics.pdf (8 pages). Each dataset also has a three-panel PNG/PDF and three standalone PNG files.
